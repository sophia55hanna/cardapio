Limpeza do Projeto

    - public/icons.svg
    - src/assets/
    - src/App.css
- Limpar:

Como rodar o Cardápio
- npm install
- npm run dev (abre o site e o JSON Server juntos)
- Os dados do cardápio ficam em db.json (API em http://localhost:3001/dias)
